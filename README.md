# 66-Vehicle-Service-Management-System_RU-26-01637_1N_Prateek-Kumar-Sihani
**Vehicle Service Management System** is a Python 3 console program built by me, Prateek Kumar Sihani. Using a ServiceRecord class and a dictionary, it adds, views, updates and deletes service records, adds 18% GST to the price list cost, validates input, and saves data to a file. All four tests passed.
